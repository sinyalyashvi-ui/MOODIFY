# MOODIFY

MOODIFY is an emotion-based music platform that turns mood into music.

## Features included in this starter build
- Mood selection with emoji cards
- Playlist generation by mood
- Dynamic music player UI
- Theme switching
- Language selector
- Premium CTA section
- Responsive desktop/mobile layout

## Local development

1. Install dependencies: `npm install`
2. Run the app: `npm run dev`
3. Open `http://localhost:3000`

## Stack
- Next.js
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Notes
This is a functional frontend prototype focused on the core MOODIFY experience and UI flow. It is designed to be extended with real backend APIs, authentication, AI mood detection, payment integration, and a production music catalog.
