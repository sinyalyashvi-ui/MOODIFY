# MOODIFY

MOODIFY is an emotion-based music streaming web app focused on mood-driven discovery, personalized playlists, and premium streaming experiences.

## Current status
This repository now includes a responsive MOODIFY app shell and a mood-detection experience with:
- emoji mood selection
- AI face scan interface
- voice analysis UI
- mood-based recommendations
- playlist updates driven by detected emotion
- premium and theme controls

## Stack
- Next.js
- Tailwind CSS
- Framer Motion
- Lucide React

## Local development
1. Install dependencies: `npm install`
2. Run the app: `npm run dev`
3. Open: `http://localhost:3000`
